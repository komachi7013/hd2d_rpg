# 星剣の目覚め

日本語の HD-2D コマンド RPG。ユウの目覚め、リリア救出、森の探索、古代神殿、黒角の獣と星剣覚醒までを遊べるプロローグです。

## 起動

```sh
npm ci
npm run dev
```

ブラウザで http://127.0.0.1:5173/ を開きます。Node.js 22.12 以上を使用してください。

```sh
npm run build
npm test
```

`dist/` は静的ホスティングに配置できます。保存は配信元ごとの localStorage です。開発環境と公開先の保存は共有されません。

## 操作

| 操作               | キー        |
| ------------------ | ----------- |
| 移動               | WASD / 矢印 |
| 決定、会話、調べる | Enter / Z   |
| メニュー、戻る     | Esc / X     |
| 選択               | 上下 / W・S |
| カメラ倍率         | ＋ / ＝ / − |
| 設定の各入力に移動 | Tab         |

北へ進み、落ちている剣を調べてから少女を救ってください。戦闘は完全ターン制。コマンド決定で1ターン進み、結果を Enter / Z で読み終えると次のコマンドを選べます。薬草は50回復。リリアは合流後、HP が50以下ならターン終了時に1回30回復します。回復した次のターンは休み、その翌ターンから条件を再判定します。休み状態は戦闘ごと・再挑戦時にリセットされます。防御はそのターンのダメージを半減します。

黒角の獣との前半3ターン後、星剣覚醒の物語が始まります。戦闘コマンド「星剣」→習得済み技能「一閃」の順で選択し、決着してください。道具も「道具」→所持品の順で選択します。一覧から Esc / X または「戻る」で戦闘コマンドへ戻れます。一覧を開く・選択を移動する・キャンセルするだけではターンを消費しません。

## 保存

冒頭、リリア合流、戦闘勝利、調べた対象、神殿到着、ボス直前、プロローグ完了で自動保存します。1枠。新規開始による上書きにはゲーム内確認があります。壊れたデータは読み込まず、説明を表示します。敗北時は直前の戦闘開始時の HP と薬草で再挑戦できます。

キー `hoshiken.prologue.v1`。JSON は版番号、マップ ID、座標、HP、薬草、同行、武器、星剣、完了、イベントフラグ、撃破 ID を保持します。描画オブジェクトは保存しません。音声設定は `hoshiken.settings`。

技能定義は `src/simulation/abilities.ts`（ID・名前・説明・使用条件・効果）、習得状態は既存の `flags` 内の `skill:<ID>` で管理します。版番号・保存フィールドは変更していません。旧セーブの `starSword: true` は「一閃」習得済みとして読み取ります。今後のイベントでは `learnSkill(state, ID)` で定義済みの技能を習得させます。

同行NPCは `src/render/party-placement.ts` で位置を管理します。戦闘・マップ・同行状態の切替、再開、位置の不連続な変更で追従履歴をリセットし、最初の描画から人物とカメラを配置します。通常歩行中は補間で追従します。

## 構成

- `src/simulation/`：物語・マップ・敵定義、保存状態、ターン解決。
- `src/render/`：Three.js、固定角度のカメラ、立体地形、スプライト。
- `src/main.ts`：入力と探索・会話・戦闘・メニューの状態遷移。
- `src/ui/`：日本語 DOM UI。
- `src/audio.ts`：自作の Web Audio BGM 2種、効果音、フェード、設定。
- `public/assets/`：実行用の生成画像。
- `art-source/`：生成元画像、抽出フレーム、方向別GIF、共通倍率とQCメタデータ。
- `docs/`：素材記録、検証結果、画面。

第一章は未実装。追加時は新しいマップ・イベントデータを追加し、セーブの `starSword`、`lilia`、`complete` を引き継ぎます。既存セーブと互換性のない変更には版番号と移行処理が必要です。

## 素材

画像は組み込み ImageGen で生成し、generate2dsprite で透過・抽出・足元揃え・QC を行いました。生成プロンプトは `docs/asset-prompts.json`。背景の立体地形は Three.js 形状です。音楽・効果音はこのプロジェクトのオリジナル合成音。外部音源は使用していません。素材詳細と検証の範囲は `docs/ASSETS.md`、`docs/QA.md` を参照してください。

Python を実行する場合は必ず `.venv/bin/python` を使用します。
