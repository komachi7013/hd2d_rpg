# 第一章「鐘の音が消える村」

2026年10月7日。引き継ぎ資料 `/Users/komachi/work/chapter-01-handover.md` に基づき、既存 Three.js / TypeScript / Vite のプロローグへ接続。

## 遊び方

プロローグ終了画面の「第一章へ進む」、またはプロローグ完了済みセーブの「つづきから」で開始。章タイトル → 翌朝のアルネ村 → 北の鐘守との会話 → 旧鐘楼 → 地下水路 → 祈り習得 → 霧憑きの鐘守 → 精霊救出 → 村への帰還・鐘の復旧 → 長老に紋章を確認 → 村の南口から街道へ。

パン職人・村の子の会話、大鐘の紐、救護箱は任意。結界の異常と祈り習得は必須イベント。第二章の交易都市は未実装で、第一章完了後は街道の探索と村・鐘楼への再訪が可能。

主人公の名前は新たに確定する場面を加えず、既存プロローグ・UIの「ユウ」を使用。

## 戦闘

第一章からリリアがプレイアブル。コマンド順は二人とも「攻撃／防御／固有コマンド／道具」。ユウの固有コマンドは「星剣」、リリアは「魔法」。各生存者に一回ずつ行動を選び、二人の行動後に敵が行動する。素早い敵は既存ルールに従い、そのラウンドの最初に先制する。先制で戦闘不能になると選んだ行動は実行されない。戦闘不能の仲間は行動順から除外。回復と祈りに蘇生効果はない。

- 一閃：64ダメージ。霧の鎧を先に解除。通常攻撃はユウ42・リリア22、鎧中は35%（切り上げ）。プロローグの黒角の獣への覚醒フィニッシュのみ従来の一撃決着。
- 回復：味方一人を42回復。対象選択後に実行。
- 祈り：ボス前に習得。戦闘中は味方一人の忘却解除、戦闘外では30回復。一閃はMP6、回復はMP4、祈りはMP3を消費。戦闘外の魔法も同じMPを消費する。
- 薬草：一人を50回復。共通所持数を消費。
- 防御：そのラウンドの敵攻撃を半減（切り上げ）。敵行動まで維持。

霧憑きの鐘守はHP360。霧の鎧は解除後2回の敵行動で再形成。敵は忘却＋小ダメージ → 予兆＋単体攻撃 → 全体攻撃を繰り返す。忘却は主にユウを対象に3ラウンドで自然解除し、薬草は封じない。リリアが忘却になっても祈りは使用可能。一閃でMPを使い切っても鎧中の通常攻撃は有効。忘却は自然解除するため、技能を使えないまま進行不能にはならない。第一章中はNPCの自動回復を無効化。

## 保存と再開

キー `hoshiken.prologue.v1` と `version: 1` を維持。既存の `complete` はプロローグ完了として残し、任意の `chapter` データを追加。第一章開始時に `{ number: 1, stage, titleShown, liliaHP }` を保存し、旧セーブは初回章開始時に拡張。`party` に二人分のレベル・経験値・現在MPを追加。これがない旧第一章セーブにはLv1・経験値0・MP24を補い、HP・技能・イベントは維持する。技能は従来の `skill:<ID>` フラグ。新しい章データの値域・形状も検証する。

タイトルは0.5秒フェードイン・2秒表示・0.5秒フェードアウト。開始から0.5秒以降のEnter/Zで短縮可能。完了した時だけフラグを保存。タイトル途中の中断は最初から、完了後の再開・再訪では再表示しない。

ボス勝利は復旧会話より先に保存。ロードすると未完了の精霊救出・結界復旧へ戻り、再戦しない。復旧・帰還・紋章・旅立ちはそれぞれフラグで一度だけ完了。旅立ち後は `chapter.number: 2`, `stage: complete`, `ch01:complete` を保存し、二人のHP、技能、星剣、薬草、既存所持品フラグを維持する。

## NPC・MP・成長・戦闘表示の追加

鐘守は新規の青い作業着の男性、パン職人はエプロン姿の大人、村の子は赤い帽子の男の子。長老は元の年配NPCを維持し、四人に異なる素材IDを割り当てる。全員2×2の待機アニメーションを使用。

初期値は二人ともLv1・最大HP100・最大MP24。勝利経験値は地下の霧憑き30、魔蛾45、鐘守100。必要経験値は40から始まり、レベルごとに30増加。Lvアップでユウは最大HP+12・最大MP+4、リリアは最大HP+10・最大MP+5。増えた最大値の差だけ現在HP/MPも増加するが、戦闘不能は回復しない。報酬は敵IDごとに一度だけ付与。

各戦闘の開始時に現在MPを最大MPへ補充。HPは引き継ぐ。再挑戦も戦闘開始時のレベル・HP・所持品に戻り、MPは最大値。技能を選択してキャンセルした時、無効な対象を選んだ時、先制で行動前に倒れた時はMPを消費しない。残りMPが不足すると該当技能を無効化し、必要MPと「MP不足」を表示。

HUDには二人のLv・現在/最大HP・現在/最大MPを表示。個々のHP変動を記録し、キャラクターと敵の上にダメージは赤のマイナス値、回復は青のプラス値を約1.5秒表示。同じ行動内で回復後に被弾した場合も両方を別表示。HUDのHP数値も直近の変動に合わせて一時的に色を変える。

防御はユウが剣を胸元に構え、リリアが腕を上げて身をかばう専用アニメーション。既存の人物と倍率を共有。味方の次の行動選択中も、そのラウンドで防御中の人物は構えを維持し、軽減された被弾時にも構えを見せる。次の攻撃を決定した際には以前の防御表示を解除する。
