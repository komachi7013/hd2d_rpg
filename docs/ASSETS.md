# 素材記録

## 画像

全て組み込み ImageGen による本プロジェクト用の生成画像。外部ゲーム作品や素材サイトからの画像・キャラクターは使用していません。OpenAI サービスの適用条件に従って使用してください。プロジェクト側では追加クレジットを必須にしていません。

| ID            | 用途                               | 処理                                                    |
| ------------- | ---------------------------------- | ------------------------------------------------------- |
| yuu           | ユウの4方向待機・歩行              | 4×4、足元、共通倍率                                     |
| attack        | ユウの攻撃                         | 2×2、body-only、ユウ共通プロファイル                    |
| hurt          | ユウの被弾                         | 2×2、ユウ共通プロファイル                               |
| star          | 星剣使用                           | 合格した攻撃シートの剣を参照編集、2×2、共通プロファイル |
| lilia         | リリアの4方向待機・歩行            | 4×4、足元。逆向きの2フレームを水平反転                  |
| heal          | リリアの手当て                     | 2×2、リリア共通プロファイル                             |
| wolf / moth   | 通常敵2種                          | 2×2、透過、統一倍率                                     |
| boss          | 黒角の獣                           | 2×2、足元、統一倍率                                     |
| fx            | 星剣の光                           | 2×2、人物から独立した FX                                |
| props         | 革袋、道標、薬草、泉、ペンダント等 | 3×3コンパクト小物                                       |
| sword         | 拾う剣・祭壇の剣                   | 単独生成、透過                                          |
| title         | 朝日の森と倒れているユウ           | 一枚絵、文字は DOM                                      |
| mural         | 勇者と漆黒の竜の壁画               | 神殿の立体壁に貼る画像                                  |
| tree          | 森の大木                           | 単独生成、透過、立体空間に配置                          |
| ground / path | 森と道の質感                       | 立体地面のリピートテクスチャ                            |

`generate2dsprite.py` は描画を作らず、生成画像の透過・フレーム抽出・整列・QC に使っています。ユウの grounded body sheets は同じ scale profile を利用し、body-scale CV ≤0.08、anchor std ≤0.05、profile drift ≤0.08 のゲートを使用しました。リリアは NPC のため、出力端接触・クランプ・空フレームの strict QC を使用。源画像と生成プロンプト、処理メタデータ、GIF を開発用素材として保持します。

祭壇・床・柱・岩などの立体背景は Three.js 形状で作成。背景モデルの外部ライセンスはありません。

## 音声

`src/audio.ts` で作曲・実装したオリジナル Web Audio 合成音です。

- 探索 BGM：穏やかな鐘系の旋律、低音、反復。
- 戦闘 BGM：短い旋律、低音、矩形波による打楽器的アクセント。
- 決定、攻撃、被弾、回復、覚醒、星剣の効果音。

外部録音・楽曲・サンプルなし。再配布する外部音源や音源クレジットはありません。

## フォント

端末内の明朝体・セリフ体を使用。フォントのダウンロードや同梱はありません。

生成元・フレーム・GIF・QC は `art-source/` に整理し、公開用には `public/assets/` の実行画像だけを配置しています。処理メタデータ内のパスは処理時点の記録です。
