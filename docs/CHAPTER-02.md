# 第二章「名前のない街」実装

2026年10月8日（日本時間）。設計資料は `chapter-02-design.md`。同資料は設計時点の文章を保存しており、その「未実装」はこの実装報告の状態を示しません。

## プレイ範囲

第一章完了後、王都へ続く街道の北端からメルカへ入る。章タイトル、住民との導入、配送控え、初回休息、管理責任者とセナ、導管の調査、セナの救出と星断ち習得、中枢の対立、コレクター戦、救護、炉停止、北方任務記録、街の復旧、出発前休息、北門から北方街道への旅立ちまで。

カイの仕事場と管理施設は市場のランドマークで Enter/Z を押して入る。仕事場からは入口のランドマークか通路端で市場へ戻る。管理施設と地下水路は通路の奥から進む。地下の通常敵2体は横を通って回避可能。救護箱は任意で薬草2個を一度だけ取得。

戦闘仲間はユウとリリアの二人。カイとセナは協力NPC。失った記憶の全面復元、主人公の正式所属、師弟関係、中核物品の正体は未確定のまま第三章へ引き継ぐ。第三章の本編は含めない。

## 採用値

| 対象           | HP  | 行動・報酬                   |
| -------------- | --- | ---------------------------- |
| 霧憑きの作業機 | 128 | 攻撃14、速さ4、経験値30      |
| 記憶喰いの魔蛾 | 140 | 攻撃16、速さ7、経験値30      |
| コレクター本体 | 360 | 経験値120。吸収器2個が各HP64 |

星断ちはMP6・単体32ダメージ。有効な吸収器への使用はHP残量に関係なくその接続を解除する。本体への使用は32ダメージ。吸収器が一つでも接続中なら本体へのダメージは半減し切り上げる。一閃は64ダメージ・MP6を維持。吸収器への通常攻撃・一閃もHP0で解除する。再接続はない。本体HP0で残る吸収器も停止する。

コレクターは二人の行動後に一回だけ行動。記憶吸収（ユウ優先、10ダメージ＋忘却、接続全解除後は忘却なし）、圧縮予兆（単体14＋予告）、記憶奔流（全体24）の3ラウンド周期。各防御はそのラウンドの被ダメージを半減。忘却は既存の3ラウンド・祈り解除を再利用。通常攻撃の威力、回復、薬草、Lv成長は既存通り。

## 保存・復帰

保存キー `hoshiken.prologue.v1`、version 1を維持。形式は既存の章・フラグ・敵IDの追加で表現できるため、バージョン更新は不要。旧プロローグおよび第一章完了のセーブも読み込む。

第二章開始時は第一章のHP・MP・Lv・経験値・所持品を保持して、章番号2・段階arrival・タイトル未完了へ移行する。第二章タイトルの完了は `ch02:title`。`ch01:title` は保持する。

必須会話は完了時にフラグを確定し、その途中でロードした場合は会話の先頭から再提示する。星断ち習得とイベント完了を同じチェックポイントに保存。コレクターの勝利は最終ターンの確認前に、撃破・経験値・`ch02:boss` を保存する。ロードは再戦ではなく救護・停止・記録の未完了会話に進む。

救護で戦闘不能の仲間をHP1へ戻し、出発前休息で最大HP・MPへ回復する。休息フラグが保存済みならロード時に再回復しない。再挑戦は戦闘開始時の状態を復元しMPを最大に戻す。

終了時はmap north-road、chapter.number 3、stage complete、titleShown true、`ch01:complete` と `ch02:complete` を保持。これは第二章完了を示し、第三章開始済みを意味しない。新技能と記録確認フラグも保持する。
