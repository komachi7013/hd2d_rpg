## 確認範囲と制限

- PC 向け。スマートフォン・ゲームパッドは対象外。
- Chromium を検証。Safari / Firefox、さまざまな実GPUでの性能比較は未実施。
- 音声 API の起動、曲切替、音量・ミュート保存を実装し、設定動作を検証。人による聴取評価は未実施。BGM は自作の短い合成音ループです。
- 通しプレイは会話とコマンドを素早く送る自動テストです。初見15〜25分という目標は、人によるプレイ時間計測と最終バランス調整が必要です。
- マップは北へ進む一本道が中心で、泉・石碑・薬草など寄り道の調べる対象を配置しています。
- 拾う剣と祭壇の古びた剣は同じ生成小物を共有。覚醒の剣は戦闘シートと光の FX で区別しています。
- localStorage が使用できない環境では保存失敗を案内し、操作を続けられます。
- 第一章は未実装。

## 2026年10月6日の修正確認

`node scripts/revision-checks.mjs` が合格。実行時エラー0件。結果は `revision-checks.json`。

- 覚醒前は星剣コマンドなし。覚醒後は「攻撃／防御／星剣／道具」の順。星剣→習得済みの一閃でボス撃破・完了保存。
- 道具→所持している薬草から使用。使用時のみ1ターン消費。薬草0個では所持品一覧に出ない。
- Esc / Xで元のコマンドへ戻り、元の選択位置にフォーカス。開閉・キャンセルでHP・ターン数は不変。

- 技能の習得IDは既存のflagsに保存。セーブのキー・版番号・フィールド集合は従来のまま。
- 実際のWorld.renderをテスト用ブラウザ内で計測し、戦闘終了・マップ切替・同行セーブ再開の最初の描画からNPCの位置が主人公の追従位置（x−1.2、y=0.05、z+1.6）と一致し、カメラも新位置と一致することを確認。
