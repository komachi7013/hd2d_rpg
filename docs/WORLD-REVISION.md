# 探索・戦闘表示の修正

2026年10月10日（日本時間）。第二章実装に対する追加修正。

## 追従

リリアは固定の左下配置から、ユウの歩いた経路を1.6ワールド単位の間隔でたどる方式へ変更した。曲がり角を斜めに横切らず、移動方向に合わせて正面・背面・左右の歩行を選ぶ。マップ移動・ロード・戦闘終了・加入の際は経路を作り直す。戦闘では既存の二人の配置を保つ。

## 戦闘

コマンドの判定結果を味方・敵・手当ての演出段階へ分ける。各段階は攻撃開始から380msで命中し、950msの動作と300msの余韻を置いて次の段階へ進む。HP、状態効果、数値表示は各命中時に更新する。演出中の決定入力は行動を進めない。

既存の素早い敵の先制、および第一章以降の生存味方が一回ずつ行動後に敵が動くルールは継承する。先制と味方の行動も別々に再生する。敵撃破時に反撃は挟まない。経験値・勝利フラグは演出完了後、結果確認前に保存する。

リリアは新しい4フレームの杖による振り下ろし攻撃を使用する。敵は踏み込み・揺れ・姿勢の変化で攻撃し、魔蛾は飛び込み時に浮き上がる。命中した対象は短く点滅する。

頭上のアイコンは防御、忘却（残りラウンド）、戦闘不能、霧の鎧、吸収障壁（残る接続数）、接続解除、全体攻撃予兆に対応する。実際の戦闘状態に従って表示・解除する。アイコンにポインターを合わせると効能を読める。

## 町・川・橋

アルネ村とメルカを横に広げ、中央通り、外側の南北路、三本の東西路、市場の広場を設けた。新しく生成した店・住宅・庁舎と、既存の倉庫・家・鐘楼を使って異なる街区を作る。

メルカの川には画像生成した水面を反復して使い、二つの石橋を架けた。水面は連続するよう原画の不透明タイルを使用し、ゆっくり流れる。川の上は橋の場所だけ通行可能。橋ではキャラクターの足元を橋面に合わせる。

建物は矩形の足元、石・小物・植生は円形の足元で衝突する。NPCも実際の位置で衝突する。以前のセーブが新しい障害物の中にある場合は、外へ離れる移動を許す。

## 人物・森

NPCは3秒正面で静止、2秒右へ歩行、3秒正面で静止、2秒左へ歩行、2秒正面で静止の周期を繰り返す。プレイヤーや他の人物・小物にぶつかる時は止まる。会話の対象位置もNPCの移動に追従する。既存の人物を参照した7種類の方向別歩行シートを生成し、左向きは採用した右向きプロフィールを反転して表示する。

森の通常敵は7ワールド単位以内のユウを毎秒1.25単位で追い、接触すると戦闘に入る。森の救出イベントの狼とボスは動かさない。植物・石・道標・荷物などに当たり判定を追加した。
