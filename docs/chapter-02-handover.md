## 1. この資料の目的と読み方

第二章のストーリー・イベント仕様を作成するため、実装済みの物語、登場人物が知っている情報、残された謎、章終了時の状態、ゲーム上の制約を引き継ぐ。

本資料の「実装済み」は、現在の会話データと処理に存在する内容を指す。第二章の事件・都市名・新人物・新技能はここでは決めない。数値は現在の実装値であり、世界観上の絶対的な法則とは区別する。

**主人公の名前について：** 当初の第一章引き継ぎ資料は「本章では名前を確定しない」としていたが、既存プロローグでは少年が自分の名前を「ユウ」と覚えている。実装済みの第一章もこの表記を継承している。第二章の連続性は「名前はユウと認識しているが、それ以外の身元・過去が分からない」を基準にする。本名か別名かなど、それ以上の設定は未確定。

## 2. 物語の現在地

記憶を失ったユウは、精霊の森でリリアを救い、古代神殿で星剣と「一閃」を獲得した。翌朝、アルネ村で記憶異常が起き、二人は旧鐘楼の地下を調査する。村を守っていた精霊が黒い霧に侵され、村とのつながりが記憶を吸い上げる経路になっていた。

ユウは精霊そのものを討たず、まとった霧を一閃で切り裂く。リリアは「祈り」を身につけ、霧による意識の混乱や戦闘中の忘却に対処する。精霊を救い、結界と鐘の働きを復旧した二人は、長老からユウの革袋の紋章が王立調査隊のものだと聞く。

**第一章の結末は、身元と記憶異常の手がかりを求めて王都へ向かい、その途中の交易都市を次の目的地とする旅立ち。現在のゲームは街道まで実装済みで、交易都市と第二章本編は未実装。**

## 4. プロローグのストーリーと到達点

### 4.1 進行順

1. **森での目覚め**：ユウは場所も過去も分からない。名前だけは覚えている。革袋、青い石のペンダント、遠くの鐘の音が提示される。
2. **叫び声と剣**：北から少女の叫び声が聞こえる。落ちている剣を拾うと、身体が戦い方を知っているように動く。
3. **リリア救出**：霧憑きの狼を退ける。リリアは薬草採取に来ていたと話し、森の異変を説明する。二人は同行する。
4. **森の奥の探索**：黒い霧を追う。精霊の泉、薬草、崩れた石碑などの寄り道がある。
5. **古代神殿到着**：青い石が温かくなり、ユウは何かに呼ばれているように感じる。
6. **黒角の獣**：祭壇の前で巨大な魔物に阻まれる。前半戦では通常攻撃だけで決着しない。
7. **星剣覚醒**：剣を弾き飛ばされ、危機に陥る。ペンダントが光り、祭壇の剣がユウの手に渡る。ユウが「一閃」を獲得する。
8. **決着と声**：「星剣」→「一閃」で獣を撃破。声が「ようやく目覚めたか」「星剣の継承者よ」と告げる。壁画が輝くが、声の主の説明はない。

### 4.2 プロローグ終了時に分かること

ユウには、思い出せない過去と、身体に残った剣の扱いがある。青い石と神殿の剣が反応し、星剣の継承者と呼ばれた。ただし、本人が勇者であること、王立調査隊員であること、竜との因縁などは確定していない。

リリアは同行しているが、プロローグの戦闘では回復専門NPC。HP50以下のユウに30回復し、その次のターンは休む。プレイヤーがリリアのコマンドを選ぶ仕組み、レベル・MPの成長は第一章から始まる。

プロローグの一閃による一撃決着は覚醒イベント固有の演出・処理であり、以降の全敵を一撃で倒す技能仕様ではない。

### 6.3 矛盾を避けるための境界

- 人間の鐘守と、ボス「霧憑きの鐘守」である守護精霊を混同しない。
- 守護精霊は救出され生存している。第一章で精霊を殺したことにしない。
- 村の結界復旧を、世界中の黒い霧の消滅や森全域の完全回復と同一視しない。
- 革袋の紋章が分かったことを、ユウの所属・職業・使命が確定したことに置き換えない。
- 祈りはユウの失われた過去を取り戻していない。深い記憶の復元、万能な治療、蘇生を既存能力として扱わない。
- 一閃は第一章では無条件の一撃撃破ではない。霧を破る性質と、限界・MP消費を継承する。
- 「星断ち」「星の解放」は未習得・未実装。元の引き継ぎ資料では後続章の技能として留保されており、第二章で解放することもまだ確定していない。
- 元の引き継ぎ資料が留保した「星核」「師の関与」「竜と勇者の真実」は、第一章では説明していない。これらの具体的な設定や解禁時期を、この資料から既定事実として補完しない。
- プロローグで聞いた鐘の音の発生源と、その時点の神殿・村の鐘の関係は明言していない。既存の手がかりとして扱い、説明が必要なら第二章以降の仕様で整理する。

## 7. 第二章へ持ち越すゲーム仕様

### 7.1 仲間とコマンド

第一章からユウとリリアの2人をプレイヤーが操作する。共通の並びは「攻撃／防御／固有コマンド／道具」。ユウの固有コマンドは「星剣」、リリアは「魔法」。リリアに星剣コマンドは出さない。第一章以降、NPC用の自動回復は行わない。

| 使用者 | コマンド → 技能 | 戦闘効果                                         | 消費MP |
| ------ | --------------- | ------------------------------------------------ | ------ |
| ユウ   | 星剣 → 一閃     | 敵一体に64ダメージ。第一章ボスの霧の鎧を先に解除 | 6      |
| リリア | 魔法 → 回復     | 味方一人のHPを42回復、最大HPまで                 | 4      |
| リリア | 魔法 → 祈り     | 味方一人の忘却を解除                             | 3      |
| 共通   | 道具 → 薬草     | 味方一人のHPを50回復、所持数を1消費              | 0      |
| 共通   | 防御            | そのラウンドの敵攻撃を半減、切り上げ             | 0      |

通常攻撃はユウ42・リリア22ダメージ。現在はレベルによる攻撃力の増加を実装していない。祈りの戦闘外効果は味方一人のHP30回復で、同じくMP3消費。回復も戦闘外でMP4を消費する。

回復・祈り・薬草は戦闘不能の味方を蘇生しない。現在、戦闘中の祈りが解除する具体的な状態異常は忘却のみ。他の状態異常の対応範囲は、追加仕様が必要。

### 7.2 HP・MP・行動の扱い

- 各戦闘開始時に二人のMPを、それぞれの最大MPまで戻す。HPは前の状態を引き継ぐ。
- 技能を実行すると使用者のMPを消費する。不足する技能は使用不可で、一覧に必要MPと「MP不足」を表示する。
- メニューの開閉、選択の移動、キャンセル、無効な対象はMP・ターンを消費しない。先制で行動前に倒れた場合は選んだ技能を実行せず、MPも消費しないが、敵の攻撃とラウンドの進行は発生する。
- 生存する味方がそれぞれ1回行動した後に敵が動く。素早い敵はラウンドの最初に先制する。戦闘不能の味方は行動順から外れる。
- 二人とも戦闘不能なら敗北。再挑戦はその戦闘開始時のHP・レベル・薬草へ戻り、MPは最大値。
- 防御は専用の構えで表示する。ユウは剣を胸元に構え、リリアは腕を上げて身をかばう。次の攻撃を選ぶと防御表示を解除する。
- HPの減少量は人物・敵の上に赤、回復量は青で約1.5秒表示。回復と被弾が同じ行動内に起きても、別々の数値を出す。HUDのHP数値も直近の変動に応じて一時的に色を変える。

**実装上の例外：** 第一章ボス勝利後の救出処理では、現在HPが0の仲間を1にする。これは章終了イベントの処理で、祈り・通常回復に蘇生能力があることを意味しない。一般的な蘇生・宿泊・休息の仕様はまだない。

### 7.3 レベルと成長

第一章の開始時は二人ともLv1、最大HP100・最大MP24。プロローグのレベル・MP成長はない。第一章開始時には二人のHPを100にするが、第二章開始時に同じ初期化を行う仕様は決まっていない。

| 使用者 | Lvごとの最大HP   | Lvごとの最大MP | Lv3の最大値 |
| ------ | ---------------- | -------------- | ----------- |
| ユウ   | 100＋12×（Lv−1） | 24＋4×（Lv−1） | HP124／MP32 |
| リリア | 100＋10×（Lv−1） | 24＋5×（Lv−1） | HP120／MP34 |

必要経験値は `40 + 30 × (現在Lv - 1)`。Lv1→2は40、Lv2→3は70。レベルアップ時に必要分を引き、余りを次に持ち越す。現在のレベル上限は50。

第一章の勝利経験値は鐘楼の霧憑き30、記憶喰いの魔蛾45、霧憑きの鐘守100。二人とも獲得し、敵IDごとに一度だけ付与する。レベルアップ時は増えた最大値の差だけ現在HP・MPも増えるが、戦闘不能のHPは増やさない。

3戦をすべて行う通常ルートでは合計175経験値となり、二人ともLv3・次のレベルへの経験値65になる。通常敵を避けた場合や旧第一章セーブを移行した場合は異なるため、第二章冒頭を「必ずLv3」と固定しない。

### 7.4 第一章ボスの具体的な攻略仕様

「霧憑きの鐘守」はHP360。開始時に霧の鎧をまとい、鎧中の受けるダメージは35%に軽減、端数切り上げ。一閃は鎧を先に破って64ダメージを与える。解除後2回の敵行動で鎧が再形成される。

敵の行動は、忘却＋10ダメージ → 単体14ダメージと全体攻撃の予兆 → 生存する二人への26ダメージの全体攻撃、の周期。主にユウを対象に忘却を付与する。忘却は3ラウンドで自然解除し、祈りでも解除できる。薬草は封じず、リリアが忘却になっても祈り自体は選べる。ただしMP不足なら使用できない。

MPを使い切っても通常攻撃は有効。第二章で新しい鎧・状態異常などを設計する際も、MP切れや状態異常で永続的に進行不能にならない対処を設ける。

## 8. 章タイトル・保存・次章への接続

### 8.1 章タイトル演出

第一章では冒頭会話より前に章番号・タイトルを表示する。約0.5秒フェードイン、2秒表示、0.5秒フェードアウト。表示中は移動・戦闘入力を停止し、開始0.5秒後からEnter/Zで短縮可能。

表示が完了した時だけ完了状態を保存し、途中で中断した場合は最初から表示する。完了後のロード・再訪では再表示しない。第二章でも共通処理を利用できるが、第二章専用の文言・完了フラグ・開始条件を追加する必要がある。

### 8.2 現在の章終了状態

```text
complete = true              # プロローグの完了。第一章完了とは別の意味
chapter.number = 2           # 次章への引き継ぎ先を示す
chapter.stage = "complete"   # 現状では第一章の完了状態
chapter.titleShown = true    # 現状では第一章のタイトル表示完了
map = "road"                 # 王都へ続く街道
flags に "ch01:complete" が存在
```

`number = 2` は第二章のストーリーが既に始まっていることを意味しない。現在の `titleShown` も第二章のタイトルを表示した記録ではない。第二章導入時には、この完了状態から新しい章の進行へ遷移させる。

保存先は配信元ごとのlocalStorage、キー `hoshiken.prologue.v1`、`version: 1`。データは以下を持ち越す。

- ユウの現在HP：`hp`。
- リリアの現在HP：`chapter.liliaHP`。
- 二人のレベル、次Lvへの経験値、現在MP：`chapter.party.hero`／`chapter.party.lilia` の `level`・`xp`・`mp`。
- 仲間・武器・星剣：`lilia`・`sword`・`starSword`。
- 薬草の残数：`herbs`。
- 技能：`skill:star-slash`・`skill:recovery`・`skill:prayer` などのフラグ。
- 紋章判明・精霊救出・結界復旧・旅立ちなどのイベントフラグと、倒した敵ID。

最大HP・MPは保存されたLvから計算する。章移行時にLv・経験値・所持数・現在HPを固定値で上書きしない。宿泊などで回復させる場合は、第二章の明示的なイベント・ルールとして決める。

### 8.3 二重実行を防ぐ主なフラグ

| フラグ                        | 用途                           |
| ----------------------------- | ------------------------------ |
| `ch01:title`                  | 第一章タイトル表示完了         |
| `ch01:keeper`                 | 鐘守の必須会話完了             |
| `ch01:belfry`                 | 鐘楼到着会話完了               |
| `ch01:ward`                   | 結界の異常確認完了             |
| `ch01:prayer`／`skill:prayer` | 祈りの習得                     |
| `ch01:boss`                   | ボス勝利・精霊救出処理へ進行   |
| `ch01:restored`               | 結界復旧・村への帰還処理へ進行 |
| `ch01:return`                 | 帰還時の鐘と会話の完了         |
| `ch01:emblem`                 | 王立調査隊の紋章判明           |
| `ch01:complete`               | 第一章の旅立ち完了             |
| `ch01:supply`                 | 救護箱の薬草取得済み           |
| `xp:<敵ID>`                   | 経験値の二重付与防止           |

ボス勝利は復旧会話より先に保存する。ロード時は未完了の復旧へ進み、再戦しない。章タイトル、習得、救護箱、経験値、紋章判明、旅立ちは重複させない。

## 9. 第二章のストーリー作成で決める事項

ここからは未確定の設計項目であり、既存の設定ではない。

1. **章番号・タイトル・開始場面**：街道から交易都市へ入るどの時点で第二章を始めるか。到着までの経過時間も決める。
2. **交易都市の名前と性格**：王都との関係、物流、人の往来、見た目、探索できる範囲。
3. **ユウとリリアが関わる具体的な事件**：交易都市でも記憶異常が起きるのか、別の事件から調査隊の手がかりを探すのか。
4. **調査隊との接点**：紋章を知る人物、記録、持ち物など。何が確認でき、何がまだ分からないかを分ける。
5. **登場人物の役割と動機**：新人物が知る情報、二人に協力／対立する理由。新規の同行者・プレイアブル加入は未確定。
6. **章で明かす情報の範囲**：ユウの身元、霧、星剣、声、勇者と竜のうち、どの謎を一段進めるか。核心の解禁は別途決める。
7. **成長・戦闘・技能習得との結びつき**：既存の一閃・回復・祈り・防御を活かす場面。新技能・新状態異常・新ボスの要否と習得時期。
8. **物資・回復・経済**：宿泊、店、通貨、装備更新、蘇生、MP回復アイテムは現在未実装。導入するならルールと物語上の位置を決める。
9. **章の結末と次の目的地**：交易都市の事件をどう決着させ、王都へ向かう旅をどう進めるか。
10. **必須・任意イベントと再開条件**：必要な手がかりは必須会話に含め、任意会話の読み逃しで行き詰まらせない。中断・ロード・再訪に対応する。

第二章仕様は「開始時の状態 → 調査／事件 → 新たな発見や成長 → 対立／決着 → 判明した情報 → 次章への目的」の流れで記述すると、第一章からの接続を確認しやすい。
